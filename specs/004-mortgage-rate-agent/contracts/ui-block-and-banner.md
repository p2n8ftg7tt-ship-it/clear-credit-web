# Contract: on-page block, banner and wording rules

The user-facing side. Everything here is generated by `tasas-texto.js` (pure text, testable in Node) and rendered by `tasas-hipoteca.js`. Copy is Spanish first; fixed strings are collected in one object so translations can be added later and flagged `TODO(NATIVE_REVIEW)` (Constitution V).

## 1. Block on `comprar-casa.html` (`#tasas`)

Reuses the existing (currently unused) `.rate-watch-section` styles: left `.rate-watch-card` (agent title with status pill, the two figures, alerts), right `.rate-delivery` (freshness + next refresh + source links + disclaimer).

| Element | Content | Requirement |
|---|---|---|
| Title / status pill | "Agente de tasas" · pill: "Al día" / "Sin actualizar" / "Aún sin datos" | FR-004, FR-008 |
| Figure 30 años, 15 años | value with `%`, change vs previous in points with ▲/▼/= and the words "sube / baja / sin cambio", "publicado por Freddie Mac el {fecha}" | FR-001, FR-002, FR-030 |
| "Revisado" / "Próxima revisión" | date of last successful publish run; next Monday/Tuesday | FR-004 |
| Alert area | one card per active alert (text from `textoAlerta`) | FR-010, FR-011, FR-032 |
| Sources area | headline source + the two signals, each with what it measures, how often it publishes, link | FR-016, Story 4 |
| Disclaimer | fixed text: "Promedios nacionales de referencia para fines educativos. No son una oferta, una aprobación ni la tasa que te darían a ti." | FR-003 |
| Stale notice | "No pudimos actualizar…" (visible only when `frescura = sin_actualizar`), figures keep their original dates | FR-008 |
| Empty state | "Todavía no está disponible" (only when `sin_datos`); rest of the page unaffected | FR-009 |
| Hidden state | whole section `hidden` when `TASAS_LANZADO` is `false` (no request is even made) or when the snapshot says `activo = false`; **after launch** an unreadable snapshot shows the honest "no disponible ahora" message instead of hiding | Constitution: no mention before setup; SC-005 |

Markup rules: section anchor `id="tasas"`; figures live in elements filled by script, **no rate number typed in the HTML** (a test pins this); works at 360 px without horizontal scroll (FR-005); status pill and alert use text, not color alone.

## 2. Banner (all pages in the banner list)

- One in-flow bar inserted as the first child of `<body>`: `role="status"`, text from `textoBanner(alerta)` (≈ one line at phone width), a link "Ver detalle" to `comprar-casa.html#tasas`, and a close button (`aria-label="Cerrar aviso"`). Not fixed/sticky, never overlays content (FR-028).
- Shows only when `activo`, at least one alert exists, and the browser has **not** dismissed that alert id (`localStorage` key `themora_tasas_aviso_cerrado`, value = alert id; every access in try/catch; if storage is unavailable the banner still works and simply reappears each visit).
- Hidden on the block's own page (the block already shows the alert there).
- Any failure (fetch, JSON, storage) → banner renders nothing and throws nothing (FR-022).

## 3. Wording rules (pinned by tests, SC-006)

Generated text MUST:

- state only **what changed**: term, direction (sube/baja), size in points, date, source (FR-011);
- for Treasury and Fed alerts, say the weekly Freddie Mac average **has not been republished yet** (FR-029), and for Fed alerts say mortgage rates are **not set directly by the Fed** (FR-032);
- never contain advice, prediction or urgency. Forbidden (case-insensitive, accent-insensitive, whole words) in every generated string: `compra ya`, `aprovecha`, `no esperes`, `espera`, `debes`, `deberías`, `te conviene`, `buen momento`, `mal momento`, `bajarán`, `subirán`, `seguirán`, `pronto`, `garantiz`, `asegur`, `ilegal`, `urgente`, and English equivalents (`lock now`, `you should`, `good time`);
- write numbers as Freddie Mac published them (two decimals for rates, up to three for the computed change, using "puntos porcentuales").

Example shapes (illustrative):

- Weekly move: "La tasa a 30 años sube 0.19 puntos porcentuales (Freddie Mac, 17 sep)."
- Treasury signal: "El rendimiento del Tesoro a 10 años sube 0.13 puntos porcentuales (Tesoro de EE. UU., 18 sep). El promedio semanal de Freddie Mac todavía no se ha vuelto a publicar."
- Fed: "La Reserva Federal cambió su rango objetivo de 3.50–3.75 % a 3.75–4.00 % (17 sep). Las tasas hipotecarias no las fija directamente la Reserva Federal. El promedio semanal de Freddie Mac todavía no se ha vuelto a publicar."

## 4. Analytics (categorical only, FR-021)

Through `window.ThemoraStats.evento` (safe if analytics is off): `tasas-bloque-visto`, `tasas-alerta-vista` (prop `tipo` = alert kind), `tasas-aviso-visto`, `tasas-aviso-cerrado`, `tasas-aviso-enlace`, and `data-umami-event="tasas-fuente-abierta"` on source links. **No** rate values, dates, amounts, alert ids or free text as properties.
