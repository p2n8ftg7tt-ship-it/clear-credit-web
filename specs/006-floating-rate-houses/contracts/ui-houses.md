# Contract: floating houses, details panel, states and wording

The user-facing side of the feature. Text is generated by `tasas-texto.js` (pure, testable in Node); rendering is done by `tasas-hipoteca.js`. Spanish first; fixed strings live in the existing `TEXTOS` object so translations can be added later and flagged `TODO(NATIVE_REVIEW)` (Constitution V).

## 1. Presence

| Condition | Result |
|---|---|
| `TASAS_LANZADO === false` (pre-launch) | No request, no markup, no houses. |
| Page has no `#tasas` section (any page other than Comprar casa) | No houses. |
| Snapshot `activo !== true` | No houses. |
| `frescura === 'sin_datos'`, or `terminos[t]` missing | That house is not drawn (FR-011). The fixed block shows its own honest message. |
| Snapshot unreachable after launch | No houses; the fixed block shows "No disponible ahora…". |
| Visitor dismissed the group (this visit) | No houses until the next visit. |
| A form field has focus, or the full-screen tool (`.fha-world`) is open | Group temporarily hidden (not dismissed); returns when focus leaves / the tool closes. |

## 2. Markup created by script

```html
<div class="casas-flotantes" role="group" aria-label="Tasas hipotecarias de referencia">
  <button type="button" class="casa" data-termino="30" aria-expanded="false" aria-controls="casasPanel" aria-label="…">
    <span class="casa-plazo">30 años</span>
    <strong class="casa-valor">6.95 %</strong>
    <span class="casa-estado">Activo</span>          <!-- or "Sin actualizar" -->
    <span class="casa-marca" hidden>Aviso</span>      <!-- shown only with an alert -->
  </button>
  <button type="button" class="casa" data-termino="15" …>…</button>
  <button type="button" class="casas-cerrar" aria-label="Ocultar las casas de tasas">×</button>
  <div id="casasPanel" class="casas-panel" role="region" aria-labelledby="casasPanelTitulo" hidden>…</div>
</div>
```

Rules: created with `createElement` + `textContent` only (never HTML from data); appended to `<body>`; **no rate number is typed in `comprar-casa.html` or in the script source** (a test pins this); the numbers above illustrate shape only.

## 3. The house (always visible)

| Element | Content | Requirement |
|---|---|---|
| Term | "30 años" / "15 años" | FR-001 |
| Rate | `formatoTasa(valor) + ' %'` (same string as the block) | FR-002, FR-016 |
| Status | "Activo" only when `estadoCasa = activo`; "Sin actualizar" otherwise | FR-006, FR-010 |
| Change | Not drawn on the icon face (keeps it small); part of the accessible name and of the panel | FR-007 |
| Alert mark | Text badge "Aviso" when `marcaDeAlerta` is true | FR-012 |
| Accessible name | "Hipoteca fija a 30 años: {tasa}, {cambio}, {publicado…}. Estado: {estado}. Abrir detalles." (with "Hay un aviso." when marked) | FR-005, SC-007 |

Shape and style: CSS pentagon (house silhouette), navy background, gold-light rate text (the term label is smaller). Position: bottom-left, fixed, `z-index: 140` (below the assistant 200 and the full-screen tool 300). Phones: side by side, compact. Desktop ≥ 900 px: stacked. Floating animation only inside `@media (prefers-reduced-motion: no-preference)`. `:focus-visible` outline. Page gets bottom padding equal to the group height so nothing is trapped behind it.

## 4. The details panel

Opened by Enter/Space/click/tap on a house; closed by Escape, the close button, or activating the same house again; focus returns to the house. One panel, content switches with the house. Non-modal, scrolls internally, `max-width: calc(100vw - 24px)`.

Sections, in order:

1. Title: "Hipoteca fija a {30|15} años".
2. Figures: rate, change ("▲ sube 0.19 puntos porcentuales"), "publicado por Freddie Mac el {fecha}".
3. "Última revisión del agente: {fecha}" — only when `ultimaRevisionEn` is known.
4. Alerts that apply to this term (`textoAlerta`), each with its source link — none if no alert.
5. "De dónde salen los números": headline source + Treasury + Fed, each with what it measures, how often it publishes, link (reuses `textoFuentes`; text `soloUnaFuente` explains the signals do not change the figure).
6. Fed line: "Las tasas hipotecarias no las fija directamente la Reserva Federal…" (the existing `FED_NO_FIJA` wording).
7. "Ver las tasas de cada prestamista": the lender links (section omitted if the list is empty) + notice: "Estas páginas muestran las tasas propias de cada prestamista, que varían según la persona." Alphabetical, unranked, opens in a new tab.
8. Disclaimer: `TEXTOS.avisoLegal` (identical to the block's).
9. Link "Ver el detalle completo" → `#tasas`.

## 5. Wording rules (pinned by tests, SC-006)

Generated text MUST:

- state only what the figure is, when it was published, what changed, and where it comes from;
- never say "en vivo", "en tiempo real", "live" or "real time" (new forbidden strings added to the test list for house text only; the daily-watch idea appears only as "Última revisión del agente: {fecha}");
- never contain advice, prediction or urgency (the existing forbidden list: `compra ya`, `aprovecha`, `no esperes`, `espera`, `debes`, `deberías`, `te conviene`, `buen momento`, `mal momento`, `bajarán`, `subirán`, `seguirán`, `pronto`, `garantiz`, `asegur`, `ilegal`, `urgente`, `lock now`, `you should`, `good time`);
- for lenders: no ranking, "mejor", "recomendado", "aprobado" or endorsement wording, and no digit-percent pattern in names or notice;
- for Treasury/Fed alerts, keep 004's notes (weekly average not yet republished; the Fed does not set mortgage rates directly).

## 6. Analytics (categorical only, FR-019)

Through `window.ThemoraStats.evento` (safe if off): `tasas-casa-vista` (`{ termino }`, once per term per page view), `tasas-casa-abierta` (`{ termino }`), `tasas-casas-cerradas`; `data-umami-event` on links: `tasas-fuente-abierta` (existing), `tasas-prestamista-abierto` (new). No rates, dates, alert ids, lender names or free text as properties.

## 7. Failure and degradation

Any error in drawing, polling or storage is caught: the houses simply do not appear (or stay as last drawn); nothing throws; the rest of the page — roadmap, loan types, comparator, fixed block — is unaffected (FR-018). Blocked `sessionStorage` → dismissal lasts only for that page view.

## 8. Refresh

Every 15 minutes while the tab is visible (and once on becoming visible after ≥ 15 minutes), re-fetch the snapshot and redraw both the block and the houses from the same object. A failed refresh leaves the last drawn figures; freshness is recomputed from their original dates.
